Connect your ORION

Upload the included ESP32 sketch with your Wi-Fi details. This dashboard listens for its readings automatically.

  1. Install PZEM004Tv30, DFRobot_HuskylensV2 and ArduinoJson 7.
  2. Copy config.example.h to config.h in the sketch folder and enter your Wi-Fi details.
  3. Upload ORION_Firebase.ino. Open Serial Monitor at 115200.
Firebase path /orion/latest

Defaults: 10 W threshold · 5-second warning · person labels only. A camera fault or stale readings pause the warning. See the included README for wiring and GitHub Pages setup.

Your current Firebase test rules allow public reads and writes until 30 October 2026. Add authentication before permanent public use.

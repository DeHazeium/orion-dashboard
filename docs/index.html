Connect your ORION

Upload the included ESP32 sketch with your Wi-Fi details. This dashboard listens for its readings automatically.

  1. Install PZEM004Tv30, DFRobot_HuskylensV2 and ArduinoJson 7.
  2. Open ORION_Complete.ino and set your Wi-Fi name and password at the top.
  3. Set ZONE_X_MIN, ZONE_Y_MIN, ZONE_X_MAX and ZONE_Y_MAX if you want a smaller monitored area. The default is the full frame.
  4. Upload the sketch. Open Serial Monitor at 115200.
Firebase path /orion/latest

Defaults: 10 W threshold · 5-second warning · only people inside the monitored area clear the warning. A camera fault or stale readings pause the warning. See the included README for wiring and GitHub Pages setup.

Your current Firebase test rules allow public reads and writes until 30 October 2026. Object labels, positions and the last-person timestamp are publicly readable while these rules apply. Add authentication before permanent public use.
